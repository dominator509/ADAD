# Checklist — Implementation (per milestone)

- [ ] Read the required docs (AGENTS, COMMANDS, PLANS, LOOP, the ExecPlan).
- [ ] Inspect existing patterns/files before editing (confirm names/APIs).
- [ ] Implement ONE milestone at a time, in order.
- [ ] Do not broaden scope; do not touch files outside "Files to Change"
      without a Decision Log justification.
- [ ] Add/adjust tests for the behavior changed.
- [ ] Run the milestone's validation command; confirm the exact expected result.
- [ ] Tick the milestone's Progress box.
- [ ] Record decisions/assumptions in the Decision Log.
- [ ] Continue to the next milestone unless a STOP condition applies.
